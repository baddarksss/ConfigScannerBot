# ConfigScanner Bot 📡

ربات تلگرامی اسکنر خروجی کانفیگ‌ها — **همان موتور اپ ConfigScanner** که حالا بدون اپ، مستقیم توی تلگرام کار می‌کنه. هر سرور با یک پروسس جدا `xray` تست می‌شه، کشور خروجی با رأی‌گیری ۶ سرویس جیو پیدا می‌شه و خروجی با **پرچم + اسم یکتا** به‌صورت فایل برمی‌گرده.

```
📱 کانال (کانفیگ‌ها)  →  🤖 ربات (اسکن)  →  📄 خروجی با پرچم + کپشن  →  📱 کانال (پست)
```

## امکانات (همون‌هایی که توی اپ داری)

| قابلیت | توضیح |
|---|---|
| 📡 اسکن کامل | vless (reality/tls, tcp/ws/grpc/**xhttp**)، vmess، trojan (ECH)، ss، hysteria2 (**salamander/gecko با هسته‌ی اصلی hysteria** — همون اپ) |
| 🏳️ تشخیص کشور | ۶ سرویس جیو در موج‌های موازی + رأی‌گیری (۲ رأی = مطمئن، ۱ رأی = کم‌اعتمادی) |
| 💀 پروب تونل مرده | خروجی‌ای که ریست فوری می‌کنه زیر ۲ ثانیه «غیرقابل دسترس» می‌شه، نه ۳۰ ثانیه ⚠️ |
| 🌐 fallback HTTP | خروجی‌هایی که TLS رو می‌بندن ولی پورت ۸۰ رد می‌شن، از ip-api HTTP کشور می‌گیرن |
| 🐌 تلاش نهایی کند | خروجی‌های کندی که فقط timeout دادن، یک تلاش ۲۰ ثانیه‌ای آخر می‌گیرن |
| 🏷️ پرچم + اسم یکتا | اسم تکراری شماره می‌گیره (2, 3…) که **قبل از اسم کانال** میاد (مثلاً «🇩 آلمان 2 \| Wpnfa») — dedup پنل‌ها سرور مختلف حذف نمی‌کنه |
| 📋 فایل لینک‌های سالم | جدا از خروجی کامل؛ با تنظیم، شامل لینک‌های بدون کشور هم |
| 🏷️ کپشن با custom emoji | همون تپ Caption اپ: قالب `{{FLAGS}}` + کد ایموجی هر کشور |
| 🟩 نوار پیشرفت | حین اسکن، درصد + خونه‌های سبز توی همون پیام آپدیت می‌شن |
| 📥 چند لیست پشت‌سرهم | چند تا لیست پشت‌سرهم بفرست؛ همه جمع می‌شن و با یک دکمه شروع می‌کنی |
| 🎨 کدهای ایموجی با اپ | وارد کردن خروجی «کپی کدها» اپ + خروجی در فرمت اپ (برعکسش هم می‌شه) + ثبت تک‌تک با دکمه |
| 📄 لاگ هر اجرا | دکمه «لاگ این اجرا» — لاگ هر ران جداست و با شروع ران بعدی پاک می‌شه |
| ⚙️ تنظیمات ذخیره‌شده | همزمانی، تایم‌اوت، زبان اسم، سافیکس کانال — روی volume باقی می‌مونن |
| 🔒 خصوصی | فقط ادمین (ID تو) می‌تونه استفاده کنه |

## چطور کار می‌کنه (موتور)

```
هر کانفیگ:
  1. پورت آزاد اختصاصی روی 127.0.0.1
  2. ساخت کانفیگ xray (SOCKS inbound + outbound سرور)
  3. اجرای xray جداگانه
  4. پروب تک‌درخواستی: ریست فوری → 💀 غیرقابل دسترس
  5. موج‌های جیو موازی: cloudflare/ip.sb → ipwho/ipinfo/country.is/ip-api(http) → تکی‌ها
  6. رأی‌گیری: ۲ رأی یکسان = کشور تأیید
  7. کشتن xray → نتیجه
```

## پیش‌نیازها

- یک اکانت [Railway](https://railway.app) (پلن رایگان یا Hobby $5/ماه کافیه)
- یک اکانت GitHub (یا مستقیم از دیسکتاپ deploy کنی)
- ~۵ دقیقه وقت

## مرحله ۱: ساخت ربات تلگرام

1. توی تلگرام **@BotFather** رو باز کن
2. `/newbot` → یه اسم بده (مثلاً `Npv Scanner`) → یه username بده (مثلاً `npvscanner_bot`)
3. BotFather یه **TOKEN** می‌ده به شکل:
   ```
   123456789:AAH...
   ```
   این رو نگه‌دار — بعد لازم می‌شه.
4. (اختیاری) `/setdescription` و `/setuserpic` بزن تا ظاهر ربات حرفه‌ای‌تر بشه.

## مرحله ۲: گرفتن ID عددی تلگرامت

1. **@userinfobot** رو باز کن (یا خودت BotFather هم می‌شه: `/myid`)
2. ID عددیت رو می‌گیره، مثلاً `123456789` — این رو هم نگه‌دار.

## مرحله ۳: deploy روی Railway

### گزینه A — از GitHub (پیشنهادی)

1. کد این ریپازیتوری رو توی یه ریپازیتوری **GitHub** (مثلاً خصوصی) بذار
2. برو [railway.app → New Project → Deploy from GitHub repo](https://railway.app/new)
3. ریپازیتوری رو انتخاب کن
4. صبر کن بیلد بشه (Dockerfile خودکار `xray` رو هم دانلود می‌کنه — اولین بار ~۲ دقیقه)

### گزینه B — بدون GitHub (دیسکتاپ)

1. [railway.app → New Project → Deploy from Folder](https://railway.app/new)
2. فولدر کد رو بکش. همین.

### متغیرهای محیطی (Environment Variables)

توی صفحه سرویس → تب **Variables** → **Add Variable**:

| متغیر | مقدار | توضیح |
|---|---|---|
| `BOT_TOKEN` | تোকِنِ BotFather | **الزامی** |
| `OWNER_ID` | ID عددی تو | **الزامی** — فقط تو می‌تونی ربات رو بزنی |
| `DATA_DIR` | `/data` | پیش‌فرض همین‌ه — اگه volume وصل کردی تنظیم نمی‌خواد |
| `XRAY_BIN` | `/usr/local/bin/xray` | پیش‌فرض — تنظیم نمی‌خواد |

> اگه خواستی نسخه‌ی دیگه‌ای از xray، هنگام بیلد `XRAY_VERSION` بده (مثل `26.7.28`) — در `Dockerfile` تنظیمه.

### Volume برای ماندگاری تنظیمات (مهم)

بدون volume، تنظیمات (کپشن، کد ایموجی، نام کانال) بعد از هر deploy از بین می‌ره. برای ماندگاری:

1. توی صفحه سرویس → **Settings** → پایین صفحه **Volumes** → **Attach Volume**
2. مسیر mount: `/data`
3. حجم ۱GB کافی‌ه (فایل `settings.json` چند کیلوبایت‌ه)

> اگه volume نزنی هم ربات کامل کار می‌کنه — فقط تنظیمات بین deploy‌ها باقی نمی‌مونه.

### شبکه

ربات با **long polling** کار می‌کنه (خودش به API تلگرام وصل می‌شه، نه برعکس) → **پورت public لازم نیست**. اگه Railway خواست «Public Domain» بگیری، بی‌خیال باش؛ اگه خواستی سرویس رو به «Worker» تبدیل کنی هم مشکلی نیست.

### بررسی کار کردن

بعد از deploy:
- **Deploy Logs** باید این خط رو نشون بده:
  ```
  bot started as @npvscanner_bot, owner=123456789
  ```
- توی تلگرام رباتت رو باز کن → `/start` → منوی اصلی با دکمه‌های ثابت و ورژن ربات میاد ✅

## استفاده

### منوی اصلی (دکمه‌های ثابت)

ورژن ربات توی همین پیام شروع (`/start`) و بخش «درباره» درج می‌شه.

```
┌──────────────────────┬──────────────────────┐
│ 📡 اسکن کانفیگ‌ها    │ ⚙️ تنظیمات          │
├──────────────────────┼──────────────────────┤
│ ️ کپشن و پرچم‌ها   │ ℹ️ درباره           │
├─────────────────────────────────────────────┤
│  ادمین‌ها (فقط برای صاحب ربات)           │
└─────────────────────────────────────────────┘
```

### 📡 اسکن

> از v1.1.0 هر بخش کیبورد مخصوص خودش رو داره: با زدن **📡 اسکن کانفیگ** فقط دکمه‌های اسکن نمایش داده می‌شن و با **↩️ بازگشت به منوی اصلی** دوباره منوی کامل برمی‌گرده. اسم کانفیگ‌های خروجی هم دیگه شماره نمی‌گیرن — هرچند تا المان باشه، همه «🇩🇪 آلمان | کانال» می‌مونن.

1. دکمه **اسکن کانفیگ‌ها** →
2. کانفیگ‌ها رو **پیست** کن (هر خط یه کانفیگ) یا **فایل .txt** بفرست
   - 💡 **چند لیست** هم می‌تونی پشت‌سرهم بفرستی — همه جمع می‌شن و پیام تأیید به‌روز می‌شه
3. تعداد کل + زمان تقریبی → **🚀 شروع اسکن** (یا **🗑️ لغو و پاک‌سازی**)
4. پیشرفت زنده توی همون پیام: `🔍 اسکن در حال اجرا… 45%` + نوار `🟩🟩⬜⬜` + آخرین سرور
5. نتیجه (به ترتیب):
   - خروجی کامل — **اول به‌صورت پیام متنی** توی باکس کد؛ اگه از یک پیام بلندتر بود، `cfgscan_results.txt`
   - `cfgscan_links.txt` — فقط لینک‌های سالم (برای وارد کردن به پنل)
   - کپشن آماده — **همیشه به‌صورت متن** (کپی‌پذیر)
   - 🎨 اگه کشورهایی کد ایموجی ندارن، لیست می‌شن تا کدشون رو ست کنی
   - منوی اصلی + دکمه **📄 لاگ این اجرا**

### ⚙️ تنظیمات

| دکمه | مقادیر |
|---|---|
| 🔢 همزمانی | 2 / 3 / 4 / 6 / 8 (پیش‌فرض 4) |
| ⏱️ تایم‌اوت | 5 / 10 / 15 / 20 / 30 ثانیه (پیش‌فرض 10) |
| 🌐 زبان اسم | فارسی / English |
| 📢 سافیکس کانال | `✅ روشن (| Wpnfa)` / `❌ خاموش` — آخر همه اسم‌ها ` | Wpnfa` اضافه می‌شه |
| 🔗 لینک بدون کشور | لینک‌های «وصل شد ولی کشور نگرفت» توی `links.txt` بیان یا نه |

> همزمانی بالاتر = سریع‌تر ولی رم بیشتری می‌خواد (هر xray ~50-100MB). روی پلن Hobby، **4** امن‌ترین انتخابه.

### 👥 ادمین‌ها (فقط صاحب ربات)

اگه می‌خوای شخص‌های دیگه هم از ربات استفاده کنن:

1. دکمه **👥 ادمین‌ها** → **➕ افزودن ادمین**
2. **ID عددی** اون شخص رو بفرست (اون شخص با `/id` توی ربات ID خودش رو می‌گیره)
3. **سطح دسترسی** رو انتخاب کن:
   - **👑 کامل** — همه بخش‌ها (اسکن، تنظیمات، کپشن، پیام کاربران) به‌جز مدیریت ادمین‌ها
   - **📡 فقط اسکن** — فقط ارسال کانفیگ، شروع اسکن، پاک کردن لیست و گزارش/لاگ + دریافت خروجی اسکن (لینک، کپشن، پیام کاربران). **به تنظیمات و بقیه بخش‌ها دسترسی نداره.**

مدیریت: توی منوی ادمین‌ها برای هر شخص دکمه **🔁 تغییر سطح** و **🗑️ حذف** هست. حذف سریع هم با `/rmadmin ID` ممکنه.

> صاحب ربات (`OWNER_ID`) همیشه دسترسی کامل داره و توی لیست دیده نمی‌شه. تغییر ادمین‌ها فقط توسط صاحب ممکنه.
> تنظیمات ربات **گلوبال**ه: هر تغییری که یکی بده، بقیه ادمین‌های کامل هم بلافاصله (با پیام «🔄 تنظیمات به‌روزرسانی شد») منوی جدید رو می‌بینن.

### 🏷️ کپشن و پرچم‌ها

- **✏️ ویرایش قالب**: هر متنی با `{{FLAGS}}` — جای پرچم‌ها. قالب پیش‌فرض همون قالب اپ‌ه.
- **🎨 کد ایموجی کشورها** (مثل تپ Caption اپ):
  - کشورهای **آخرین ران** با پرچم + اسم + کد فعلی‌شون لیست می‌شن
  - روی دکمه‌ی **✏️ هر کشور** بزن → کد عددی رو پیست کن (یا `delete` برای حذف)
  - **📥 وارد کردن (از اپ)**: توی اپ «کپی کدها» بزن و اینجا پیست کن (فرمت `DE=…` — همون فایل بکاپ اپ هم می‌شه)
  - **📤 کپی (برای اپ)**: همه کدها در فرمت دقیق اپ برمی‌گرده؛ توی اپ «بازیابی از فایل» بزن و پیست کن
  - بعد از هر اسکن، کشورهایی که کد ندارن جداگانه یادآوری می‌شن
- **👁️ پیش‌نمایش**: کپشن با کشورهای آخرین ران ساخته می‌شه.

## به‌روزرسانی

- **کد ربات**: pull کن → Railway خودکار rebuild می‌کنه (اگه از GitHub deploy کرده باشی).
- **xray**: خط `ARG XRAY_VERSION=...` توی `Dockerfile` رو عوض کن → push → deploy. (همون ورژنی که اپ آپدیت می‌کنه؛ الان `26.7.28`.)

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| ربات جواب نمی‌ده | ۱) Deploy Logs: خطای `BOT_TOKEN is required`؟ متغیرها رو چک کن. ۲) لاگ باید خط `update ...: chat=... msg=...` رو بعد از هر پیامت نشون بده — اگه هیچ `update` ای نیومد، چند ثانیه صبر کن و دوباره `/start` بزن. ۳) اگه `start of the range` دیدی نگران نباش — ربات خودش offset رو به آخر می‌رسونه و ادامه می‌ده. |
| «⛔ این ربات خصوصی‌ه» | `OWNER_ID` رو با `/id` یا @userinfobot چک کن — باید ID **عددیت** باشه نه @username. |
| همه سرورها ❌ | Logs رو ببین (deploy logs) — اگه `xray binary not found` بود، بیلد شکست خورده. |
| بعضی سرور ❌ که از ایران سالمه | **منتظره** — موتور از IP سرور Railway (US/EU) تست می‌کنه و بعضی پروایدرها دیتاسنتر رو فیلتر می‌کنن. برای اینا اپ گوشی مرجع دقیق‌تره. |
| ران خیلی طول می‌کشه | همزمانی رو بالاتر ببر (اگه رم کافیه) یا تایم‌اوت رو کمتر. |
| `out of memory` در logs | همزمانی رو 2-3 کن یا پلن بالاتر بگیر. |

## سؤالات متداول

**چرا بعضی کانفیگ‌ها اینجا «غیرقابل دسترس» می‌شن ولی توی اپ/گوشی سالم‌ان؟**
نتیجه‌ی اسکن به **IP مبدأ** وابسته‌ست. Railway روی دیتاسنترهای US/EU‌ست و بعضی سرورها دیتاسنترها (یا کشورها) رو فیلتر می‌کنن. این محدودیت ذاتی هر اسکنر ابریه — اپ گوشی (مبدأ: ایران) همیشه مرجع دقیق‌تره.

**آیا می‌تونم خروجی رو مستقیم کانال بفرستم؟**
فایل‌ها رو از ربات بگیر و توی کانال بفرست. اگه بعداً بخوای، می‌شه یه feature «فرورود خودکار به کانال» هم اضافه کرد (بات صاحب کانال باشه).

**چند سرور در هر ران؟**
حد فنی خاصی نیست؛ ۱۰۰ سرور با ۴ همزمانی ≈ ۱۵-۲۵ دقیقه.

**ورژن xray چنده؟**
`26.7.28` (همون ورژنِ baked اپ). با تغییر `XRAY_VERSION` در Dockerfile عوض می‌شه.
